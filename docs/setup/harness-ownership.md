## What it does

`harness-ownership` は、ハーネスの所有者（DRI）と構成レビューの周期を `docs/agents/harness-owner.md` に残します。3〜6か月ごと、または主要なモデルのリリース後に性能が頭打ちだと感じたときに見直す、という運用を日付付きで書きます。日付が無いと見直しは起きない、という前提のスキルです。

## When to reach for it

`/harness-ownership` と打ちます。Claude が自分で開くことはありません。

- 他の層を整えた最後に使います。
- 一人で使うリポでも、次回の見直し日を1行残すために使う価値があります。

## Common questions

**DRI は何を決める人ですか。**
設定、権限ポリシー、プラグインマーケットプレイス、CLAUDE.md の規約を決める権限と、それらを最新に保つ責任を持つ人です。専任チームがあるなら通常は開発者体験や開発生産性を担う部門が持ちます。

**文書を書けば見直しは起きますか。**
文書だけでは通知が来ません。次回見直し日をカレンダーなどリポの外のリマインダーにも入れてください。

## It's working if

- `docs/agents/harness-owner.md` に DRI と次回見直し日が書かれています。
- `harness-audit` のオーナーシップが「充足」になります。
- 見直しのたびに、変更履歴の表に1行増えています。
