## What it does

`harness-hooks` は、CLAUDE.md の「必ず〜」「〜しないこと」のうち譲れないものをフックに移し、機械的に強制します。入れるのは4本です。編集後のフォーマットと型チェック（PostToolUse）、不可逆操作の停止（PreToolUse）、応答終了時に人の訂正を CLAUDE.md への追記候補として溜める（Stop）、セッション開始時に起動ディレクトリに応じた一言を渡す（SessionStart）。設定は起動ディレクトリの `.claude/settings.json` に書きます。

## When to reach for it

`/harness-hooks` と打ちます。Claude が自分で開くことはありません。

- CLAUDE.md に「必ず lint を通す」「本番に push しない」のような文があるのに守られないときに使います。
- どの操作を止めるかは対象リポごとに違うので、提案書の中でパターンを編集して構いません。

## Common questions

**フックのスクリプトが見つからないと言われます。**
サブディレクトリから起動していて、フックがルートの `.claude/settings.json` にある場合、その設定は読まれていません。起動ディレクトリの設定に入れ直してください。パスは `${CLAUDE_PROJECT_DIR}` で始めます。

**Stop フックは CLAUDE.md を勝手に書き換えますか。**
いいえ。候補を `.claude/harness-kit/claudemd-candidates.md` に溜めるだけです。採用するものを人が選んで CLAUDE.md か rules に移します。

**python3 も node も無い環境ではどうなりますか。**
4本のフックは stdin の JSON を解釈するのに python3 または node を使い、どちらも無い場合、またはあっても実行に失敗する場合（例: pyenv shim が未導入バージョンを指す）は sed/grep による簡易抽出にフォールバックします。特に `guard-irreversible.sh` は、フォールバック時、および command を取り出せなかった場合（不正な JSON・command 空を含む）に必ず stderr へ警告を出したうえで、通常と同じパターン照合を続けます。危険なコマンド（`rm -rf` 等）は簡易抽出でも変わらず止めますが、ネストした引用符など一部の複雑な書き方は正しく取り出せず見逃す場合があります（複数行のコマンドは実際の改行・タブに復元してから判定するため、簡易抽出でも通常どおり止まります）。対象リポに python3 も node も無いなら、この制約を導入前に人に伝えてください。

## It's working if

- ファイルを1つ編集すると、フォーマットが自動で掛かります。
- 故意に型エラーを入れると、同じターンの中で Claude が指摘を受けて直します。
- 履歴を書き換える push を頼むと、実行前に止まって理由が表示されます。
- 新しいセッションの最初に、起動ディレクトリ名と溜まっている候補の件数が表示されます。
