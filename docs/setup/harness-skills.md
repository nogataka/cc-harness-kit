## What it does

`harness-skills` は、CLAUDE.md に残っている手順やチェックリストをスキルへ、特定のディレクトリだけの規約を `paths` 付きの rules へ切り出します。スキルの本文はタスクで必要になったときだけ読み込まれ、rules は一致するファイルを Claude が読んだときだけ読み込まれます。CLAUDE.md には「いつ何を使うか」の1行だけが残ります。

## When to reach for it

`/harness-skills` と打ちます。Claude が自分で開くことはありません。

- 監査で「CLAUDE.md 内の番号付き手順」が5行以上あるとき、リリースやレビューの手順が CLAUDE.md にあるときに使います。
- [harness-claudemd](harness-claudemd.md) から移動項目が申し送られていれば、それを一緒に処理します。

## Common questions

**スキルと rules のどちらにすればよいですか。**
手順（何をどの順でやるか）はスキル、規約（特定のファイル種別でこう書く）は rules です。領域ごとに置きたいならスキルはその領域の `.claude/skills/` に、規約は `paths` の glob で領域を絞ります。

**スキルが自動で開かれません。**
`description` の先頭に、依頼文に含まれそうな語があるかを見てください。スキルが増えると説明文は短く切られるため、後ろに書いた条件は読まれません。

## It's working if

- 切り出した手順が CLAUDE.md から消え、参照の1行だけが残っています。
- 新しいセッションで `/名前` と打つと、作ったスキルが一覧に出ます。
- `paths` に一致するファイルを読ませたときだけ、規約に沿った振る舞いになります。
